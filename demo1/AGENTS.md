# demo-website

## Projekt

- Vite-Website mit React.
- Einstiegspunkt ist `src/main.jsx`.
- Hauptseite ist `src/App.jsx`.
- Globale Styles liegen in `src/styles.css`.

## Befehle

- `npm run dev` startet den lokalen Entwicklungsserver.
- `npm run build` erstellt den Produktionsbuild.
- `npm run preview` zeigt den Produktionsbuild lokal an.

## Hinweise

- `node_modules/` nicht manuell bearbeiten.
- Bestehende Dateien in `src/assets/` und `public/` nur aendern, wenn es fuer die Aufgabe noetig ist.
